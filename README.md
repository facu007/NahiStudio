# NAHI STUDIO — Creative Portfolio (`Two Sides. One Identity.`)

Proyecto recreado directamente desde **Stitch** (`projects/5419191138370308234`).
Unifica **01 — Nail Art** y **02 — Tattoo Art** bajo un mismo universo editorial oscuro (`#111111` Obsidian, `#F1ECE5` Bone White, `#C7C7C7` Chrome Silver y `#8B2635` Oxblood Ink).

## Estructura del Proyecto

- `index.html`: Página principal completa (*Nahi Studio — Two Sides, One Identity*), con moneda interactiva 3D de dos caras, galería asimétrica de Nail Art con fotografías reales, visor modal Lightbox, agenda de turnos Nail Art conectada a WhatsApp, catálogo de Flash Book & Tattoo Art, formulario de consulta de tatuajes y sección biográfica.
- `tailwind.config.js`: Configuración de tokens del sistema de diseño (colores, tipografías `Playfair Display`, `Raleway` y `Spline Sans Mono`, espaciados y curvas de transición).
- `DESIGN.md`: Documentación completa del sistema de diseño **Nahi Studio — Design System**.
- `design-tokens.json`: Tokens exportados del sistema de diseño de Stitch.
- `components/`: Biblioteca de componentes base (`button.html`, `card.html`, `input-field.html`, `modal.html`).
- `assets/images/`: Fotografías reales y recursos gráficos descargados localmente desde Stitch.

## Cómo ejecutarlo localmente

Podés abrir `index.html` directamente en tu navegador o iniciar un servidor local:

```bash
npm start
```
